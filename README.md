# voice-vocabulary-agent

A simple voice agent that helps people learn vocabulary. It reads a word's meaning aloud, you say the word, and it gives feedback, hints, and an example sentence.

**Live demo:** https://shareefunnisa-syed.github.io/voice-vocabulary-agent/
(Best in Chrome or Edge. Allow the microphone.)

## How it works
- Uses the browser's built-in speech synthesis to talk and speech recognition to listen
- Voice commands: "hint", "repeat", "skip", "stop"
- 8 words per session with a score
- You can type answers if the microphone is not available
